# AnyKey Chat

Android-приложение для общения с любыми AI-моделями по **твоим** API-ключам — от OpenAI, Anthropic,
Google Gemini, OpenRouter, Groq, DeepSeek, локального сервера или любого стороннего/приватного
прокси («пиратские» ключи и зеркала тоже работают, если у них OpenAI-, Anthropic- или Gemini-совместимый API).

## Что умеет

- 💬 **Чаты**: история диалогов, стриминг ответа по буквам, остановка, перегенерация, копирование,
  markdown с таблицами и кодом, автоназвания чатов.
- 📎 **Вложения**: картинки (vision-модели) и текстовые файлы прямо в сообщение.
- 🔑 **Хранилище ключей**: сколько угодно ключей, у каждого свой провайдер, базовый URL, модель,
  произвольные заголовки.
- ✅ **Проверка валидности в один тап**: сначала бесплатный запрос списка моделей, если провайдер
  его не отдаёт — минимальный пробный запрос на 1 токен. Отдельно различаются «ключ не принят»,
  «нет денег», «rate-limit», «сервер недоступен». Есть кнопка «Проверить все».
- 🔎 **Автоопределение провайдера**: вставляешь ключ — приложение само перебирает десяток известных
  API и показывает, где он живой.
- ⚙️ **Настройки на чат**: модель, системный промпт, температура, лимит токенов.
- 🔒 **Безопасность**: ключи лежат только на телефоне, в приватном хранилище приложения. По желанию
  включается PIN — тогда ключи шифруются AES-256-GCM (ключ выводится из PIN через PBKDF2, 210k итераций).
- ⬆️⬇️ Экспорт/импорт ключей и чатов.

Никакого своего бэкенда: телефон обращается к API провайдера напрямую. Для обхода CORS в WebView
используется нативный HTTP-слой Capacitor, стриминг идёт обычным `fetch` с автоматическим откатом
на не-стриминговый запрос.

## Как получить APK

В репозитории лежат конфиги сразу для нескольких сборщиков — достаточно любого одного.

### Вариант 1. Codemagic (рекомендую, 500 бесплатных минут/мес)

1. [codemagic.io](https://codemagic.io) → войти через GitHub → **Add application** → выбрать этот репозиторий.
2. Выбрать **Use codemagic.yaml** (файл `codemagic.yaml` уже в корне).
3. **Start new build** → workflow `AnyKey Chat — Android APK` → ветка с кодом.
4. Через ~5 минут в артефактах сборки будет `AnyKeyChat.apk` — можно скачать прямо на телефон.

### Вариант 2. CircleCI (~6000 бесплатных минут/мес)

1. [circleci.com](https://circleci.com) → войти через GitHub → **Projects** → **Set Up Project** для этого репозитория.
2. Выбрать «Fastest — use the existing config» (`.circleci/config.yml`).
3. После сборки APK лежит во вкладке **Artifacts** запуска.

### Вариант 3. GitLab CI

Зеркалишь репозиторий в GitLab — конфиг `.gitlab-ci.yml` соберёт APK, файл будет в артефактах job'а.

### Вариант 4. GitHub Actions

Workflow `.github/workflows/android.yml` собирает APK при каждом пуше и публикует его в релиз
`android-latest` (прямая ссылка, удобно открыть с телефона). Работает только если на аккаунте
GitHub не заблокированы Actions (при блокировке билдинга job падает с «account is locked due to a
billing issue»).

### Установка на телефон

Открой скачанный `AnyKeyChat.apk` в файловом менеджере и разреши установку из этого источника
(Android спросит сам).

По умолчанию собирается **debug**-APK (устанавливается без проблем, но подпись меняется от сборки
к сборке — при обновлении может потребоваться сначала удалить старую версию).

### Подписанный release-APK (по желанию)

Создай keystore и добавь секреты репозитория:

```bash
keytool -genkey -v -keystore release.keystore -alias anykey -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.keystore   # значение для ANDROID_KEYSTORE_B64
```

Секреты: `ANDROID_KEYSTORE_B64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. (только для GitHub Actions).

## Локальная разработка

```bash
npm install
npm run dev        # веб-версия в браузере
npm run build      # сборка веб-части в dist/
npx cap sync android
cd android && ./gradlew assembleDebug   # нужен Android SDK + JDK 21
```

Иконки пересобираются из `resources/icon-full.png`: `node scripts/gen-icons.mjs`.

## Структура

```
src/lib/api.ts        запросы к провайдерам (openai / anthropic / gemini), стриминг, проверка ключей
src/lib/detect.ts     автоопределение провайдера по ключу
src/lib/providers.ts  пресеты провайдеров
src/lib/store.ts      состояние приложения (zustand) и вся бизнес-логика
src/lib/crypto.ts     AES-GCM + PBKDF2 для шифрования ключей
src/screens/          экраны: чат, ключи, настройки
android/              нативный проект Capacitor
```

получил, лежит на тебе.
